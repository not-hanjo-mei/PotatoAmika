# De-esser 原型（离线验证版）

算法一句话：5 kHz 零相位高通幅度分频（高频支路 = 高通，低频支路 = 原信号减高频，增益为 1 时逐值精确重构），检测用高频支路与宽带的能量比，超过阈值的部分按斜率换算成高频增益衰减（封顶 6 dB），增益在 dB 域做攻击/释放平滑，低频支路原样直通、从不被处理。

实现：`work/deess.py`（纯 numpy，无 scipy）。处理后样本在 `samples-deessed/`。

## 参数表（定版）

| 参数 | 值 | 说明 |
|---|---|---|
| sample_rate | 32000 Hz | 与现有样本一致；换采样率时所有 Hz/ms 参数按比例重算 |
| crossover_hz | 5000 | 分频点 |
| hp_order | 6 | 高频支路幅度响应 1/sqrt(1+(fc/f)^12)，零相位（整句 FFT） |
| split_pad_ms | 100 | FFT 分频前两端反射填充，消边界效应，处理后裁掉 |
| env_tau_ms | 3.0 | 检测包络：对 hi² 和 x² 各做指数平均（等效一极点平滑） |
| thr_db | −5.0 | 检测量 R = 10·log10(env(hi²)/env(x²))，R 高于此值开始衰减 |
| slope | 1.5 | 每超出阈值 1 dB → 衰减 1.5 dB |
| max_gr_db | 6.0 | 衰减封顶 |
| attack_ms | 0.5 | 增益平滑：衰减加深时的时间常数（dB 域） |
| release_ms | 50.0 | 增益平滑：衰减恢复时的时间常数（dB 域） |
| gain_grid_ms | 0.5 | 增益在 0.5 ms 网格上平滑后线性插值到逐样本 |

调参依据：阈值 −5 dB 取自响帧比值分布的双峰分界（常态帧 R 多在 −10 dB 以下，齿音帧集中在 −3~0 dB）；斜率 1.5 是在 −6/1.0、−5/1.5、−5/2.0 三组里选的中间档，三组效果接近，1.5 的低频代价和整体变暗程度居中。

- 增益强制为 1 时输出与原信号逐值误差 ≤ 6e-17（浮点级精确重构已验证）。

## 往 C++ 宿主搬的注意事项

1. 逐句处理：宿主本来就逐句合成、逐句裁静音，de-ess 放在合成后、裁静音之前，对整句缓冲跑一遍即可，成本是一对 FFT 加一遍 O(n) 时间域循环，相对 TTS 推理可忽略。
2. 状态不跨句保留：每句开始时包络和当前增益都清零（增益从 0 dB 起）。把释放尾巴带进下一句会把下一句的句首预先压暗，禁止。
3. 分频实现可替换但幅度响应要一致：原型用整句 FFT 零相位分频；宿主若要流式逐块处理，换成线性相位 FIR 高通（32 kHz 下约 129–257 抽头，延迟 2–4 ms）并保持同样的幅度形状。不要用因果 biquad 的 x−LP 互补分频：相位滞后会让高频支路在低频段出现很大的相位瓣，衰减时会啃中低频。低频支路必须保持「原信号减高频支路」的互补构造，这样增益 1 时精确重构、低频支路天然直通。
4. 参数都是 Hz/ms 的物理量，宿主里按实际采样率换算成系数，不要把 32 kHz 下算好的系数写死。
5. 检测不需要电平门限：静音段 R 无定义但衰减了也听不见，原型靠 1e-18 下限兜底即可；宿主保持同样处理，不要加额外的噪声门，免得句首辅音被门限吞掉。
6. 增益平滑的网格和插值别省：0.5 ms 网格加线性插值是防咔哒声的，逐样本直接跳变增益会引入调制噪声。

## 6 kHz 变体（A/B 对比用，未定版）

目的：用户提出过渡带上移 1 kHz 试听。本节只加变体和数字，不改上面的 5 kHz 定版。脚本 `work/deess6k.py`，原始指标在 `work/deess6k_metrics.json`。改动只有 crossover_hz 5000 → 6000，其余参数（hp_order 6、env_tau 3 ms、slope 1.5、max_gr 6 dB、attack 0.5 ms、release 50 ms、gain_grid 0.5 ms）与定版相同。6 kHz 下增益强制为 1 时重构误差 ≤ 5.6e-17，精确重构保持。

阈值复核（按定版同样的双峰分界方法重取）：交叉点升到 6 kHz 后高频支路变窄，响帧 R 分布整体下移，逐文件 R 中位数降 0.7–1.4 dB（样本级口径）。用等触发覆盖率对齐定版：定版（5 kHz、thr −5）在帧级响帧中 R 高于阈值的占 25.6%；6 kHz 下 thr −5 只剩 24.1%，thr −6 为 25.9%，与定版对齐。故重取阈值为 **−6 dB**，作主样本（后缀 `_deess6k`）；thr −5 不变的版本另跑一份（后缀 `_deess6k_thr5`）作对照。本节表格的 6 kHz 列均为 −6 版，−5 版只在读法里给关键数字。

口径注：本节数字全部由 `work/deess6k.py` 按定版同口径重算（20 ms 帧、10 ms 步进，响帧 = 帧 RMS ≥ 原文件最大帧 RMS 的 3%，响帧掩码取自原文件，Hann 窗），三方（原版 / 5 kHz / 6 kHz）同脚本同口径。占比均值、>11k 占比、频谱重心、最刺帧降幅与定版表接近；p90 和 LTAS 距离因聚合细节不同，绝对值与定版表有出入，比较以本节三方为准。本节 LTAS 距离定义：响帧平均幅度谱，带内 mean(|Δ幅度谱|) / mean(原幅度谱)。

### deess2air 的亮度账

- 空气架把重心从 deess2 的位置抬回 +113~+173 Hz，但仍比原版低 234–481 Hz：按重心口径没有回到原版附近。原因是节目材料的 >11k 能量集中在 11–13 kHz，架在那里的增益只有 0~1 dB，全文件 >11k 能量实际只抬了 +0.70~+1.10 dB（不是 +3 dB，+3 dB 只在 16 kHz 一个点上）；而 deess2 在 5–11k 压掉的量更大，重心被那一段主导。
- >11k 占比 deess2air 仍低于原版（例：w4_p08 0.110 对原版 0.126；fp32_s0 0.026 对 0.031），空气段没有被抬过头。
- W4 与 fp32 分开看：架对 >11k 能量的相对抬升，w4 三条 +0.88/+0.92/+1.10 dB，fp32 两条 +0.87/+0.70 dB，w4 略大，因为 W4 的 >11k 能量分布更靠高频、吃到的架增益更多；但抬升后 w4 的 >11k 占比仍低于其原版（w4_p06 0.058 对 0.077、w4_s0 0.040 对 0.043），没有把 W4 的高频多余量放大到超过原版。

读法与风险：

- 压深到位程度：六条里五条最刺帧降幅 −7.7~−9.5 dB（v1 是 −4.7~−5.9），进到 −9~−10 量级边缘；各文件 GR 最大值 9.94–10.00 dB，最刺帧普遍吃满新上限。注意比值检测量 R 天然 ≤ 0 dB 左右，斜率 2.0 时 GR 理论上限本就约 10 dB，这一轮的封顶与斜率给出的深度基本重合。
- 例外是 w4_p08（绕口令）：只到 −6.33 dB。它的最刺帧是宽带也响的密擦音帧，R 的超出量本身小，比值检测在这种帧上天然压不满；这不是封顶卡住（该文件吃满 10 dB 的样本只占 2.6%）。要再压它只能换检测量或动阈值，本轮按约束没动。
- 主体仍未伤：<4k LTAS 距离 0.0022–0.0062，全文件 <4k 能量变化 −0.002~−0.009 dB，仍在 0.01 dB 量级内，与 v1 持平。
- 4–5k 过渡带代价随 GR 加深变大：全文件 4–5k 能量 −0.89~−2.42 dB（v1 是 −0.69~−1.88），LTAS 距离 0.099–0.204。这是压得更深必然多付的部分，与 6 kHz 节的结论一致：代价搬不走，只能选落在哪一段。
- 听感不在本节下结论，deess2 与 deess2air 样本并排在 `samples-deessed/`，由用户判。
